# Radial Plots for Matplotlib

A hands-on guide to building radar (spider) charts in Python using Matplotlib - from a minimal polar subplot to a fully custom projection with polygon framing.

---

## Learning Objectives

- Understand what radar/spider charts are and when to use them
- Build a basic radar chart using Matplotlib's built-in polar subplot
- Extend Matplotlib with a custom `RadarAxes` projection that constrains chart content inside a polygon frame
- Control axis angles, labels, fills, and legends on polar axes
- Save publication-quality figures to disk

## Step-by-Step Walkthrough

### Basic Radar Plot

The standard approach uses Matplotlib's built-in polar coordinate system. You manually compute the angle for each axis by dividing a full circle (2*pi radians) into equal slices, then call `ax.plot()` and `ax.fill()` once per data series.

The key trick is repeating the first value at the end of every data list - this closes the polygon so the filled area looks connected rather than open.

This approach is the right starting point when your chart has few series and you want the default circular frame.

### Advanced Radar Plot (Custom Projection)

When you want the chart clipped to a polygon boundary rather than a circle, you need to register a custom Matplotlib projection. The notebook defines `radar_factory(num_vars, frame)` which:

1. Computes evenly spaced angles and rotates them so the first axis points up
2. Defines `draw_poly_patch` and `draw_circle_patch` as the two possible frame shapes
3. Subclasses `PolarAxes` as `RadarAxes`, overriding `fill` and `plot` so they auto-close the plotted polygon, and `_gen_axes_spines` so the spine follows the polygon path instead of a circle
4. Registers the new projection so `fig.add_subplot(projection="radar")` just works

The polygon clipping is the reason for the custom projection - Matplotlib's built-in polar axes always use a circular clip region.

## Key Concepts Glossary

| Term | Definition |
|------|-----------|
| Radar chart | A chart that displays multivariate data on equidistant axes radiating from a center point. Also called a spider chart or web chart. |
| Polar axes | A coordinate system where position is given by an angle and a radius rather than x and y. |
| Theta | The angular coordinate in polar notation; computed as evenly spaced fractions of 2*pi. |
| `register_projection` | Matplotlib function that lets you define a named axes type (`projection="radar"`) reusable across figures. |
| `PolarAxes` | Matplotlib's base class for polar coordinate plots; subclassed here to add polygon framing. |
| Spine | The border line drawn around an axes object. Overridden here to follow a polygon path. |
| `fill` / `ax.fill` | Draws a filled polygon between the plotted points and the chart origin, giving the colored area inside a radar trace. |
| Polygon frame | A straight-sided boundary (pentagon, hexagon, etc.) used instead of the default circular clip region. |
| `bbox_inches="tight"` | `savefig` argument that trims whitespace around the figure before saving. |
| Custom projection | A named Matplotlib axes class that can be passed to `add_subplot(projection=...)` to get non-standard axis behavior. |
